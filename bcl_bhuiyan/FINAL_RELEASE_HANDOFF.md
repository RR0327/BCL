## Backup and recovery
- SQLite: use `encrypted_backup` and `verify_encrypted_backup` with a protected Fernet key; verify isolated recovery.
- PostgreSQL: run `postgres_rehearsal` against a staging PostgreSQL instance with `pg_dump` and `pg_restore` installed. Backups generated by this tool are **not encrypted** and must be protected and encrypted before long-term storage.
- Keep database dumps, media, secrets, and logs separate; database-only restoration cannot restore missing media files.
- Before any live deployment, document recovery time objective (RTO), recovery point objective (RPO), monitoring, incident escalation and tested rollback.
